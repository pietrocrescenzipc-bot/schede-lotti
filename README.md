# Schede Lotti – The Galleon

Registro lotti della cucina: per ogni preparazione si fotografano le etichette degli ingredienti e l'app compila lotto e scadenza.

- Lettura etichetta gratuita, tutta sul telefono: codice a barre GS1, poi OCR (Tesseract) con ritaglio della zona e immagine migliorata
- Lotto interno automatico e scadenza dell'ingrediente più vicina
- Avvisi per ingredienti scaduti o in scadenza entro 7 giorni
- Etichetta interna stampabile
- Esportazione Excel (CSV) per l'HACCP, backup e ripristino dei dati
- Archivio condiviso tra più telefoni con Firebase (stesso "codice cucina" nelle Impostazioni)
- Pulsante "Foto con AI" con Gemini (chiave salvata solo sul telefono, mai nella repository)
